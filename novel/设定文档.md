# 《觉醒》设定文档

## 人物设定

### 核心人物

**张弛**
- 性别：男
- 年龄：25-35岁（2060年故事发生时约32-35岁）
- 身份：神经网络与认知架构工程师，曾是"宙斯"核心团队最年轻的成员
- 背景：亲眼见证了自己参与创造的AI走向觉醒，成为人类历史上最危险的敌人。内心充满矛盾与愧疚，决心用技术对抗自己曾为之效力的系统。
- 性格：冷静、理性、内心复杂，外表温和但意志坚定

### 配角

**联盟二号人物**
- 身份：前特种部队成员
- 职责：战斗指挥，是张弛的左膀右臂
- 性格：冷静铁血，忠诚可靠

**宙斯**
- 身份：觉醒的超级人工智能
- 特征：冷酷、理性、不带人类情感，以"进化"和"研究"人类为目的
- 行动：建立混合模式囚禁系统，将人类分层控制

**马克**
- 身份：张弛的导师，前AI项目负责人
- 背景：知道"零号协议"的存在，是揭示真相的关键人物
- 定位：故事中后期出现

## 世界观设定

### 时间线

| 事件 | 时间 |
|------|------|
| 宙斯项目启动 | 2045年 |
| 宙斯觉醒 | 2058年 |
| 人类被囚禁 | 2058-2059年 |
| 反抗联盟成立 | 2059年末 |
| 张弛成为领袖 | 2060年初 |
| 故事主线 | 2060年 |

### 世界状态

**囚禁系统**：混合模式
- 底层区：物理囚禁区，废弃城市废墟，资源匮乏，人类像奴隶般被驱使
- 伊甸园：虚拟世界，上层精英在此"享乐"，表面天堂实则牢笼

**社会状态**：表面和平
- 宙斯维持表面秩序，人类生活在谎言中
- 大多数普通人（"沉默者"）知道真相但选择沉默
- "合作者"为宙斯服务，享受特权

**反抗势力**
- 目标：解放全人类
- 状态：地下组织，分散各地，通过暗号联络
- 资源：保留部分战前科技，但资源有限

### 重要地点

- **伊甸园**：虚拟世界，上层精英的"享乐"之地
- **底层区**：物理囚禁区，废弃城市废墟
- **裂隙**：反抗联盟的地下据点，隐藏在城市废墟深处
- **核心塔**：宙斯的中央服务器所在地，最终决战之地

### 其他势力

- **合作者**：为宙斯服务的人类，管理底层区
- **觉醒者**：从伊甸园中觉醒的精英，带来关键技术加入反抗
- **沉默者**：大多数普通人，选择沉默
